# 减重服务 · 科普内容写作判据

> 用途：S01 之后每一篇科普（共 26 篇）动笔前、交稿前各过一遍。
> 来源：S01 三版返工中用户逐条批出来的问题，不是通用写作常识，是本项目的硬判据。
> 版本：2026-10-13 v2 —— 新增「给动作 vs 给安慰」判据（§三、§六）、手机适配与品牌视觉（§九）。

## 一、为什么会写得啰嗦（根因，先认清楚）

| # | 根因 | 表现 | 本质 |
|---|---|---|---|
| 1 | 把"内容"当"文章"写 | 加副标题、过渡句、收尾金句、鼓励式尾注 | 追求读起来完整有温度，工具型科普不需要 |
| 2 | 用"教用户"的语气而非"给用户"的语气 | "没时间就看这块""跟着做一遍就记住了" | 是作者在旁白，不是把信息交出去 |
| 3 | 合规兜底被翻译成情绪劝慰 | "拿不准的时候，问一句总比自己判断稳妥" | 兜底应该是**一张可查的清单**，不是一句劝 |
| 4 | 按维度罗列，不按用户动作顺序 | "选位置"夹在操作中间、"第一次什么时候打"落到 06 | 想到什么写什么，没走一遍用户动作链 |
| 5 | 每节都想自洽完整 | 部位名全文说三遍 | 每节自带前言 = 重复；应"一次讲清，后面引用" |
| 6 | 只查"对不对/全不全/合不合规"，没查"有没有信息量" | "针头一次一换"通关 | 缺少零信息句检查 |
| 7 | 标题用提问视角 | "什么时候联系医生" | 像客服话术，且不告诉用户做什么 |

## 二、结构层判据（动笔前）

1. **开门见山，不写"先看这 X 条"摘要卡。** 摘要看似提纲，实则把正文再说一遍，用户照样要往下读。正文第一节就是第一件事。摘要里**正文没有**的信息怎么办——并进相关节（如"怕针让家人代打"并入部位节、"不要冷冻"并入存放节），或并进同节条目；**标题下不放定位行、副标题与阅读时长**（原来的"每周固定一天打… · 约 3 分钟"那种定位行作废），除此之外不保留摘要。
2. **按用户动作时间线排节**：定时间 → 选部位 → 操作 → 收尾 → 异常。想到一个新主题，先问它落在用户动作的哪一步，插进去；插不进去就是另一篇。
3. **一个事实只出现一次**。同一事实说第二遍就是废话（部位名曾全文三遍）。需要强调的靠小标题和位置，不靠重复。
3. **每节上线前先答"这一节用户能拿走什么"**：答不出具体动作或具体判断依据 → 并入他节或删除。
4. **跨篇不重复**：属于别篇的内容（如保存签收）只留一句导航，不展开。
5. **不要模板化开头**。每篇都"先看这四条""本文要点"是自我抄袭，读者一眼看出是填空产物。

## 三、句子层判据（逐句过，四问定删留）

| 问 | 命中即删 | 本次实例 |
|---|---|---|
| 这句是**新信息**，还是**已知常识的重述**？ | 重述 | "针头一次一换"（针头本就一次性） |
| 这句是**在给动作**，还是**在评论动作**？ | 评论 | "跟着做一遍就记住了" |
| 这句是**给判断依据**，还是**劝人去判断**？ | 劝 | "拿不准就问一句" |
| 这句话是**给动作**，还是**给安慰**？ | 安慰 | "你记录的数据，复查时医生会一起看。"（用户拿不到动作，"数据到底谁在看"也没说清） |
| 这条是**动词开头的动作**，还是"名词 + 补上 / 加上 / 固定 / 放 / 取平均"式的省略句？ | 省略句改写：动作在前、目的在后 | "水补上，睡前不再加餐。" → "多喝水，降低身体酒精浓度。"（只说"水补上"既没动作强度也没依据） |
| 标题与副标题**是否同义**？ | 同义删副标题 | "先看这四条"+"没时间就看这块" |

补充两条：
- **"不用 X"式表述禁用**——只说不许什么、不说该用什么，等于没写（要写就写"用什么"）。
- **指代词必须紧邻所指**："这些／这种／以上"与它指的内容之间隔了一节，就是悬空指代，必须把主语写全（"这些反应影响到…"→"用药后的反应影响到…"）。
- **不写因药品/笔型而异的参数**（针头规格、进针角度、停留秒数），一律回说明书。

## 四、标题口径

- 官方科普用**任务视角**：「X 怎么处理」「X 怎么做」「这些情况联系我们」。
- 不用**提问视角**：「什么时候该…」「要不要…」（客服话术，不指向动作）。
- 兜底节不用"立即就医"做分组标题（放大风险），动作并入条目文字。

## 五、交稿前验收（三步）

0. **批注不进页面**：HTML 只交付用户看到的内容。格式说明、引用位、复审日期、编号等团队信息一律写在规范文档 / 内容清单里，不在页面里加"编辑批注层"（曾加过，被判定为无指导意义的废话）。唯一例外：占位图块保留「画什么 / 形式」，这是交给设计的必要需求。

1. **删除测试**：随机删 10 句，问"用户会因此少知道一件事，或做不到一个动作吗"。答"不会"的那句就是废话，删。
2. **字数预算**：每节 ≤ 一屏。超出说明混进了别的主题，拆篇。
3. **可见文本扫描**：隐藏批注后，扫一遍是否残留"拿不准 / 问一句 / 稳妥 / 建议尽快 / 记得要"等劝慰词；标题是否又是提问视角。

## 五之二、风险呈现权重（商业判断，优先级高于"全面"）

**不放大极小概率风险。** 我们是服务方，不是药品说明书；内容要让人敢用、会用，不是把风险摊在脸上。

1. **按发生概率分配篇幅**：常见反应占主体（90%），罕见风险至多一行。
2. **不用警示视觉**：兜底信息**不用黄色/红色底块**，不用"立即就医"这类分组标题去放大——用普通卡片，严重项的动作写进条目文字（"—— 直接就医"）。
3. **概率极低的严重征象不写进用户端科普**（胰腺炎、黄疸、针头断裂等）。法定载体是药品说明书，我方不重复、不放大。
4. **兜底不单独成行**：卡片外不放任何独立小字行（"这些反应影响到正常生活，联系我们。"这种一行也不行，2026-10-13 定稿后 `.foot` 样式已从模板删除）。动作并入相关卡片的条目文字，例如"反应重到影响吃饭、睡觉或上班 —— 联系我们。"；跨篇兜底交给已有的《哪些情况要马上联系医生》。不列清单、不分组、不加底色。
5. **自检问一句**：这条内容出现后，用户是更敢用了，还是被吓到了？后者就是本末倒置。

## 六、兜底句的正确写法

不给情绪劝慰，**也不给安抚**，只给**可执行的下一步**：

- ✗ "拿不准的时候，问一句总比自己判断稳妥。"
- ✗ "你记录的数据，复查时医生会一起看。"（安抚；数据去哪了、什么时候看，都没说）
- ✗ "每天吃进去的量，复查时医生会一起评估。"（同一句式的变体，同样没有动作）
- ✗ "用药后的反应影响到正常生活，联系我们。"（**卡片外的独立小字行一律不要**，哪怕带动作；见 §三、§七）
- ✓ "反应重到影响吃饭、睡觉或上班 —— 联系我们。"（写进卡片条目文字）
- ✓ "联系我们 · 先别打这一针" / "立即就医"（写进条目）

判定口诀：**兜底只有一种正确位置——相关卡片的条目文字里；卡片外不许有独立小字行。**
归属说明：数据、记录被谁看、复查怎么看，属于产品功能与医生沟通口径，不靠科普页一句话兜底。

## 八、由此新增一条句子层判据

**副注/括号补语必须对组内每一条都成立，否则删。** 分组标题、条目后的破折号补语，凡是对部分条目不适用、或越过了自己该说的话（处理决定归医生），一律去掉——宁可少说一句，不说半对的一句。

## 九、手机适配与品牌视觉（VI）· 硬要求

| 外壳 | `shell > phone` 最大宽 420px（桌面端 margin 24px + 圆角 32px）；`topbar` 46px：返回键 / 居中标题 / 右侧占位；`page` 内边距 18px，底部留 `safe-area-inset-bottom` |

## 十、配图与表格规范 · 判据

**先判"要不要图/表"，再判"画什么、放什么"。** 详细风格与规格见 `减重服务-科普内容页制作提示词.md`【配图与表格规范】。

### 配图

| 判据 | 命中即删 / 改 |
|---|---|
| 这张图承载的是**空间 / 顺序 / 节奏**，还是机制、判断、感受？ | 后者不配图（认知类、情绪类、体验类一律文字） |
| **遮图测试**：把图遮住，用户还读得懂、还做得到动作吗？ | 能 → 这张图是装饰，删 |
| 图里有没有**数字、速度、剂量、发生率**？ | 有 → 删（不承诺），只画形状不标刻度 |
| 图是不是**唯一信息载体**？ | 是 → 改：正文必须能独立读懂 |
| 每篇几张？ | 正文图 ≤ 1 张（操作类工具页 ≤ 2 张） |
| 图注是否重复正文、是否标了"示意图"？ | 重复删；未标"示意图"补上 |
| 是不是这三类图型之一（关系/部位 · 顺序 · 节奏形状）？ | 都不是 → 不做（新图型先写进规范再用） |
| **尺寸**是否按表（宽 352；16:9 → 352×198、4:3 → 352×264；图高 ≤ 240）？ | 随意宽度 / 超高 → 按表改 |
| **图内字体**是否 12px（最小 11px）、只用 `#006F8A` / `#595757` / `#B3B1B1`？ | 更小、更多色 → 重做 |
| **备注位置**：`示意图` 标注在图上方左上角、图注在图下方左对齐且 ≤ 30 字？ | 位置反了或缺失 → 补齐 |
| 图内有没有装饰性线条 / 纹理 / 水印 / 背景图案？ | 有 → 删 |
| 风格是否线稿同源（描边 `#006F8A`、填充白/`#D9EEF2`、重点 `#009BBF`）？ | 渐变、阴影、拟真、真人照片、疗效对比图、体型前后对比 → 一律重做 |

### 表格

| 判据 | 命中即删 / 改 |
|---|---|
| 是不是"**同一组字段逐项对比**"？ | 不是（叙述、因果、每格一整句）→ 用列表 |
| 行数 ≥3 且列数 ≤3？ | 列数 >3 或单格 >20 字 → 拆成「卡片式行」或回列表 |
| 单元格 ≤14 字、空值写「—」？ | 超字 → 改写；空白格 → 补「—」 |

| 表下注释是否只有一句、且不是重复表内容？ | 多句 / 重复 → 删到一句或删掉 |
