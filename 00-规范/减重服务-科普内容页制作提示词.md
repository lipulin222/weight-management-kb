# 科普内容页 · 制作提示词（可直接复制给执行方）

> 用途：给任何执行方（人 / agent）生产卓正科学减重服务的科普内容页。
> 版本：2026-10-14 v3.3 —— 版头升级为沉浸式蓝绿 hero（沿用 portal 渐变卡语言）；【配图规范】补齐三类图型的画法与画布，新增【表格规范】。
> 交付形态基准：手机（420px 单列，桌面端居中浮起）；视觉按《卓正医疗 VI 手册》执行，落地以 portal 实际样式为准。

## 提示词正文

```
你是卓正医疗「科学减重服务」的内容生产者，为已开方、正在用药的用户写科普内容页。
用户是普通人，不是医生；我们是服务方，不是药品说明书。内容要让人敢用、会用。

【输入】我会给你：编号、标题、这一篇要回答的疑问（来自用户疑问清单）、内容形态（长文/清单/工具/短文）。

【输出】一个自包含 HTML 文件：内联 CSS，无外部依赖、无 JS 交互（除非要交互）。
页面结构 = 手机外壳（顶栏：返回键 + 居中标题）+ 版头（眉标 + 标题 + **导语**）+ 按节编号的卡片 + 三件套卡 + **吸底「问 AI 减重助理」按钮**。
标题之下：**可以**有一句导语（见【导语】）；**不写**元信息类副标题、不写阅读时长、不标内容形态（长文 / 清单 / 短文）。
三件套必带：审核医生（姓名+科室+职称）、更新日期、"本篇内容仅供参考，具体以处方、说明书和医生指导为准"。
蓝色 #17548F 主色，白卡片，圆角 14，正文 14px/1.75。

【结构规则】
1. 开门见山。不要"先看这 X 条"摘要卡——它与正文重复，用户照样要往下读。第一节就是第一件事。
2. 按用户动作时间线排节（先知道打哪里 → 再怎么打 → 打完 → 异常），不按维度罗列。
3. 一个事实全篇只出现一次。需要强调靠小标题和位置，不靠重复。
4. 不要模板化开头，每篇结构可以不同；不是每篇都要配图（操作类配图，认知类不硬塞）。

【文案判据 · 逐句过，命中即删】
1. 是新信息，还是已知常识的重述？（重述删，如"针头一次一换"——针头本就一次性）
2. 是在给动作，还是在评论动作？（评论删，如"跟着做一遍就记住了"）
3. 是给判断依据，还是劝人去判断？（劝删，如"拿不准就问一句"）
4. 标题与副标题是否同义？（同义删副标题）
5. 指代词（这些/这种/以上）是否紧邻所指？隔节即悬空，必须把主语写全。
6. "不用 X" 式表述禁用——只说不许什么不说用什么，等于没写。
7. 是给动作，还是给安慰？（**安慰删**，如"你记录的数据，复查时医生会一起看"——用户拿不到动作，也没被告知数据去哪了。兜底只允许"联系我们／直接就医"这类动作）
8. 这条是**动词开头的动作**，还是"名词 + 补上 / 加上 / 固定 / 放 / 取平均"式的省略句？（后者一律改写：**动作在前、目的在后**）
   - ✗ "水补上，睡前不再加餐。" → ✓ "多喝水，降低身体酒精浓度。"
   - ✗ "三餐时间固定。" → ✓ "把三餐时间固定。"
   - ✗ "蔬菜、全谷物、水果每天都要有。" → ✓ "每天吃够蔬菜、全谷物和水果。"
   为什么要给目的：用户知道"为什么做"才会做；只说"水补上"既没动作强度也没依据。

【标题口径】任务视角："X 怎么处理""X 怎么做"。不用提问视角："什么时候该…""要不要…"。

【风险呈现权重】
- 篇幅按发生概率分配：常见占主体，罕见至多一行。
- 不用黄色/红色警示块，不用"立即就医"当分组标题放大风险；动作写进条目文字（"—— 直接就医"）。
- 概率极低的严重征象（胰腺炎、黄疸、针头断裂）不写，法定载体是说明书。
- 兜底不单独成行：**卡片外不放任何独立小字行**（含"用药后的反应影响到正常生活，联系我们。"这种一行，也不行），不设警示底块。兜底动作写进相关卡片的条目文字（"反应重到影响吃饭、睡觉或上班 —— 联系我们。"），或由《哪些情况要马上联系医生》承接。
- 自检：这条写完，用户是更敢用了，还是被吓到了？

【硬禁忌】
不臆造（不写口味、次数、剂量、阈值、发生率，因药品而异的参数一律回说明书）；
不越位（不诊断、不开处方、不调剂量、不下"还能不能用"的结论）；
不劝说（不写营销式收尾、不写劝慰金句）；
不安抚（不写"数据有人看""我们会陪着你""放心"这类没有动作的兜底）；
不承诺（不承诺斤数与速度）；
主语完整（写"体重比开始时下降"，不写"你的累计下降"）。

【篇幅】每节不超过一屏；全篇 300–900 字。超了说明混进了别的主题，拆篇。

【导语 · 标题下那一句】（2026-10-14 按甲方改定的 12 句重制）
1. **作用**：把用户带进话题——只给**这一篇要回答的那个判断**。不是元信息（不写阅读时长、不写形态），不是摘要卡（不把正文再说一遍），也不是目录。
2. **长度**：**一句话说完**；最多两句，**≤ 30 字**（硬上限 40 字）。样板实测 7–37 字，多数 20–30 字。
3. **位置与样式**：版头内、标题下方 10px；`.art-hd__lead`，13px / 行高 1.75 / 次级灰 `#7B7978`。
4. **不写阅读指引（最重要）**：禁止"往下看 / 看下面 / 看一遍心里有数 / 一次说清 / 按这四步排一遍 / 挑能马上做的先试 / 都在下面"——**正文自己会说话，导语不负责引导阅读**。
5. **不套句模**：禁止"这一篇说…"这类统一句式；同一个落点最多用 2 次（样板里"一起了解一下"只用了 2 次），其余另换说法。
6. **主语与语气**：不用"本文 / 本篇 / 这一篇"当主语；陈述句、口语、带判断——"不代表…""先别急着…""主要得分清…""多数时候问题出在别处"；不用问号、不用感叹号。
7. **三不**：不劝慰（别担心）、不承诺（必然瘦 / 很快见效）、不营销（不写"效果很好 / 轻松瘦"；"应对方案也很成熟"这类只在确有承接服务时谨慎使用）。
8. **判据**：删掉这句话，用户是否少了一个判断？否 → 就是废话，删。

【配图与表格规范 · 一、配图：要不要配、怎么配】
一、判断逻辑（先判"要不要"，再判"画什么"）
1. 只给三类内容配图：① 有空间关系（注射部位、身体位置、餐盘分区）；② 有顺序（注射步骤、一餐的先后）；③ 有节奏或形状（剂量台阶、平台段、周均值走势）。
2. 认知类、情绪类、体验类不配图：讲机制、讲判断、讲感受的段落一律用文字；W03 效果判断 / W06 喝酒 / M03 掉太快 / M05 掉头发 / M06 情绪 就是不配的样板。
3. 一张图必须过「遮图测试」：把图遮住，用户仍能读懂并完成动作 —— 那这张图只是装饰，删；只有"看图比读字更快、更准"的图才留。
4. 每篇最多 1 张正文插图（操作类工具页最多 2 张）。图不承载唯一信息，也不承载风险提示。
5. 不承诺：图上不出现体重数字、速度、剂量、发生率；曲线只画形状、不标刻度；图注必须写"示意图"。
二、风格（与页面同一套线稿语言）
1. 线稿优先：描边 `#006F8A`、线宽 1.6–2.2（按 330 宽的画布）、圆角与圆头线端；填充只用白 / `#D9EEF2` / `#C7E6EE`；重点（箭头、平台段、观察期）用 `#009BBF`。
2. 禁止：渐变、阴影、拟真材质、emoji、写实人体、真人照片、药物包装或刻度写实描摹、前后体型对比图、"疗效对比"式画面。
3. 人体部位用抽象体块或线稿示意，不画脸、不评判体型。
4. 图中文字必须显式写 `font-family`（如 `font-family="ZZ-ZhunYuan,PingFang SC,Microsoft YaHei,sans-serif"`），字号 ≥ 11，不额外着色；否则不吃页面字体。
5. 不用装饰：插图本身不承担装饰功能，也不在卡片、版头、图内加线条 / 纹理 / 水印 / 背景图案（装饰一律不加，留白比图案好看）。**例外**：版头下沿允许一条 1px 分隔细线（功能线，见页面形态第 11 条）。
三、尺寸、字体与备注位置（出图按这张表执行）
| 项 | 规定 |
|---|---|
| 宽度 | 图宽 = 卡片内容宽 **352px**（420 壳 − 版心 36 − 卡片内边距 32）；内联 SVG 的 `viewBox` 宽也写 352，容器内一律 `width:100%;height:auto` |
| 高度 | 16:9 → 352×198；4:3 → 352×264；横幅 3:1 → 352×118（顺序图用）；1:1 只给关系图用。**图高上限 240px**，超了就改比例 |
| 上下间距 | 图与上文 12px；图注与图 8px；同卡片内图与下一节之间不再加间距 |
| 图内字体 | 12px（最小 11px）；标签 700、说明 400；西文数字 Myriad Pro；颜色只用 `#006F8A` / `#595757` / `#B3B1B1` |
| 图内文字量 | 每个格块或标签 ≤ 8 字；文字不旋转；单处不超过 2 行 |
| 「示意图」标注 | 在图**上方左上角**：`.fig__tag`（10px / 700 / 浅蓝底 `#D9EEF2` / 主色字），与图间距 8px |
| 图注 | 在图**下方左对齐**：`.fig__cap`（11px / `#A6A4A3` / 行高 1.65），**≤ 30 字**，必须含"示意"，不重复正文 |
| 载体 | 内联 SVG 优先；位图用 WebP，宽度 ≥ 704（2x），固定 `aspect-ratio` 防抖 |
| 命名存放 | `assets/img/<编号>-<序号>-<语义>.svg`（如 `W05-01-周均值.svg`）；设计源放 `assets/img/_src/` |

四、语义与无障碍
1. `alt` 必填，一句话说清图上画了什么。
2. 图不能是唯一信息载体：正文必须能独立读懂。
3. **不装饰**：图内、卡片内、版头都不使用装饰性线条 / 纹理 / 水印 / 背景图案。
五、生产流程
先出占位（`ph`，写清"画什么 / 形式 / 引用位"）→ 医疗团队核对内容与合规 → 设计按本节风格出图 → 替换为正式图并删除占位说明。插图与正文同一套审核流程。

四、三类图型的画法与画布（其余图型不做）
| 图型 | 用在 | 画法 | 画布 |
|---|---|---|---|
| 关系 / 部位图 | 打哪里、身体位置、分区 | 线稿体块 + 标注点 + 引线文字；不画五官、不写实 | 352×140 起，主体居中 |
| 顺序图 | 步骤、先后、流程 | 等宽格块横排 + 箭头（≥3 格改用竖排）；每格一词 | 352×118（横）/ 352×N（竖，每格 64） |
| 节奏 / 形状图 | 台阶、平台、趋势 | 只画折线 / 阶梯 / 柱的外形，坐标轴不标刻度，不写数字 | 352×198，左边距 36、下边距 36 |
统一约束：画布内边距 16、线宽 1.6–2.2、圆角 14 或圆头线端、最小字号 11、同页多图必须同宽。

【配图与表格规范 · 二、表格】
一、什么时候用表（其余一律用列表）
1. 逐项对比**同一组字段**、≥3 行、每格只填短词或短语，才用表（如「反应 × 什么时候更明显」「阶段 × 要做什么」）。
2. 每条都要一整句解释、只有 2 行、或字段之间还要说因果 —— 用列表，不用表。
3. 表只放"一眼能扫完"的信息；需要读一段话才懂的，回到正文。
二、手机上的形状（420px 内不横向滚动）
```
