## 怎么用

| 想干什么 | 打开 |
|---|---|
| 看有哪些内容、进度到哪 | `index.html`（全量清单 40 条，可按状态筛、可搜） |
| 改某篇文案 | `editor-offline.html`（在线版：左预览右改稿，改完导出本页 md）<br>`start-editor.bat`（本机版：能直接保存并回灌页面、发布） |

## 页面硬要求（新篇生产必须遵守）

手机优先（420px 单列）· 卓正 VI 色板（主色 `#006F8A`、节标题青色 `#009BBF`）· 标题方正粗圆 / 正文方正准圆 / 数字 Myriad Pro（本地 `@font-face`，禁止网络字体）· 无 JS、无外部依赖 · 不在品牌字体上写 `font-weight` 加粗。

文案上不允许：卡片外的独立小字行 · 安抚句（"复查时医生会一起看"）· 副标题 / 阅读时长 / 形态标签 · 剂量、次数、发生率等因药品而异的参数（一律回处方与说明书）。

本机 `github.com:443` 被阻断，HTTPS 推送与 `gh auth login` 都走不通，**统一走 SSH**（`git@github.com:lipulin222/weight-management-kb.git`，22 端口可用）。
